# 测试与发布

## 本地冒烟测试

```bash
bash scripts/smoke.sh
```

自动完成：构建 → 起 server/client/三个测试目标（2 个 HTTP、1 个 UDP echo）→ 验证 8 项
（随机路径 404、面板、客户端在线、TCP 正向/穿透/反向、UDP 穿透/反向）→ 自动清理进程与临时文件。

前置条件：本机装有 Go 与 `py`（Windows Python 启动器）或 `python3`。

## 打包

```bash
bash scripts/package.sh 0.1.0        # 参数为版本号；缺省取 git tag，无 tag 用 dev
```

- Windows zip + Linux tar.gz，产物在 `dist/`
- 二进制 `-trimpath -ldflags "-s -w"` 并用 upx --best 压缩（未装 upx 自动跳过）
- 包内：`caochuan(.exe)`、`conf/*.example.json`、`deploy/caochuan.service`、启停脚本、README

## CI/CD（GitHub Actions）

- `.github/workflows/ci.yml`：每次 push / PR 在 ubuntu + windows 双平台 `go build` + `go vet`
- `.github/workflows/release.yml`：推送 `v*` tag 时，在 ubuntu 上安装 upx → `scripts/package.sh` 打包
  → 以 tag 名（去掉 v 前缀作为版本号）创建 GitHub Release 并上传两个压缩包

发版流程：

```bash
git tag v0.1.0 && git push origin v0.1.0   # 等待 Actions 完成即发布
```

## 排障速查

| 现象 | 排查 |
|---|---|
| 客户端不在线 | 本机 client 进程活着吗；token 与面板一致吗；`telnet 服务器 7000` 通吗 |
| 规则不通 | 面板看规则是否「运行」；正向/穿透看安全组 TCP；UDP 看安全组 UDP |
| 面板 403 | 来源 IP 不在白名单（页面错误信息里会带 IP）；client 在线时其来源 IP 自动放行 |
| 面板 404 | 路径少了/错了随机前缀；或访问的是根路径 |
| 反向规则「停止」 | 看规则行错误备注（多为客户端侧端口被占）与客户端日志 |
