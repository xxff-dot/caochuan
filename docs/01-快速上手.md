# 快速上手

caochuan（草船）是单二进制的 TCP/UDP 转发与内网穿透工具，带 Web 管理面板。
服务端跑在公网服务器上，客户端跑在内网机器上，客户端无需任何规则配置，规则全部由面板集中管理并自动下发。

## 三个概念

| 方向 | 链路 | 典型用途 |
|---|---|---|
| 正向 | 服务器端口 → 任意目标 | 把服务器某端口转发到另一台机器/端口 |
| 穿透 | 服务器端口 → 客户端内网目标 | 公网访问内网服务（NAS、家庭设备等） |
| 反向 | 客户端端口 → 服务器侧目标 | 内网机器借服务器网络访问外部/服务器内网 |

TCP 与 UDP 均支持；UDP 数据封装在客户端与服务器的 TCP 隧道内传输。

## 服务端（公网服务器）

```bash
./caochuan server
```

首次运行自动生成 `conf/server.json`，并在控制台打印随机生成的面板密码与客户端 token。

## 客户端（内网机器）

```bash
./caochuan client
```

首次运行生成 `conf/client.json` 模板，填好后重启：

```json
{
  "server_addr": "服务器公网IP:7000",
  "token": "从面板「客户端」页获取",
  "tls_fingerprint": "服务器启动日志/面板概览里的证书SHA-256指纹（推荐填写，防中间人）"
}
```

客户端保持运行即可，断网自动指数退避重连；规则由服务器自动下发，无需重启。

## 第一次转发

1. 浏览器打开 `http://服务器IP:7500/<随机路径>/`（启动日志里会打印完整面板地址，免密模式下直接进入）
2. 「客户端」页确认客户端在线
3. 「转发规则」→「＋ 新建规则」：选协议、监听端口、方向、目标地址；可选配来源白名单、限速、连接数上限
4. 规则保存即生效（约 1 秒内下发），无需重启

目标地址的解析视角：
- 正向 / 反向：从**服务器**视角解析（可以是服务器自身 `127.0.0.1:xx`、服务器内网 `172.x.x.x:xx`、或任意公网地址）
- 穿透：从**客户端**视角解析（`127.0.0.1:5000` 即客户端本机的 5000 端口）
