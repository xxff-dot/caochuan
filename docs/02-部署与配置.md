# 部署与配置

## 打包分发

```bash
bash scripts/package.sh 0.1.0
```

产出 `dist/caochuan-<版本>-windows-amd64.zip` 与 `caochuan-<版本>-linux-amd64.tar.gz`：
二进制经 upx 压缩（未安装 upx 自动跳过），包内含 `conf/` 示例配置、`deploy/` systemd 模板、启停脚本。

也可以直接源码编译：

```bash
go build -o caochuan.exe ./cmd/caochuan                                   # Windows
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -ldflags "-s -w" -o caochuan ./cmd/caochuan
```

## Linux 服务端（systemd）

```bash
mkdir -p /opt/caochuan/conf
cp caochuan /opt/caochuan/ && chmod +x /opt/caochuan/caochuan
cp deploy/caochuan.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now caochuan
journalctl -u caochuan -f          # 看日志
```

注意把 `caochuan.service` 里的 `-c` 路径改为实际配置路径。更新版本时：
`systemctl stop caochuan` → 覆盖二进制 → `systemctl start caochuan`。

## Windows 客户端（系统服务，需管理员）

```
caochuan service install -role client -c C:\caochuan\conf\client.json
caochuan service start | stop
caochuan service remove
```

服务开机自启，崩溃 5 秒后自动拉起。更新版本先 `service stop`，覆盖 exe，再 `service start`。

Linux 客户端同样用 systemd：把 ExecStart 改为 `caochuan client -c ...`。

## 配置参考（server.json）

```jsonc
{
  "tunnel_addr": "0.0.0.0:7000",   // 隧道监听，客户端连这里
  "panel_addr":  "0.0.0.0:7500",   // Web 面板监听
  "password":    "xxxx",           // 面板密码（no_auth=true 时忽略）
  "no_auth":     false,            // 免密模式：跳过登录，仍受白名单与随机路径保护
  "panel_prefix":"399eea80",       // 面板随机路径前缀；留空启动时自动生成
  "ip_whitelist": [],              // 手动白名单，支持 IP 或 CIDR，如 "192.168.1.0/24"
  "secret":      "...",            // 会话签名密钥，自动生成，勿改
  "clients": [
    {"name": "home-nas", "token": "...", "note": "备注"}
  ],
  "rules": [
    {"id": "ab12cd34", "name": "web",
     "side": "server",             // server=监听在服务器(默认)；client=反向，监听在客户端
     "proto": "tcp",               // tcp | udp
     "listen": 8080,               // 监听端口
     "client": "home-nas",         // 空=正向；穿透/反向填客户端名
     "target": "10.0.0.2:80",      // 目标地址
     "enabled": true}
  ]
}
```

配置保存为原子写（临时文件 + rename），面板上的所有修改即时落盘并热生效。

## client.json

```json
{"server_addr": "服务器IP:7000", "token": "面板里复制的token"}
```

## 面板访问控制（三层）

| 层 | 说明 |
|---|---|
| 随机路径 | 面板挂在 `/<panel_prefix>/` 下，根路径与其他路径一律 404，扫描器找不到入口 |
| IP 白名单 | 放行集合 = 本机回环 ∪ 本机网卡地址 ∪ `ip_whitelist` 手动配置 ∪ 在线客户端来源 IP（自动） |
| 登录密码 | `no_auth=false` 时需要密码，5 次失败锁该 IP 10 分钟；`no_auth=true` 免密 |

> 本机网卡地址自动放行是为了「反向隧道访问面板」可用——那种请求的源地址是服务器自己。

## 云安全组提醒

穿透/正向的规则端口必须在云厂商安全组放行；注意 **TCP 和 UDP 要分别添加**。
反向通道不受影响（客户端主动外连隧道，服务器侧无需为它开入站端口）。

## 安全边界

- 隧道使用 token 鉴权但数据**不加密**；对安全性要求高的公网链路请自行套 TLS 或改用加密隧道
- `conf/server.json` 中的密码、token、secret 为明文，注意文件权限（600）
- 免密模式务必配合随机路径 + 白名单使用
