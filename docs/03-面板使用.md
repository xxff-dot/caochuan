# 面板使用

浏览器打开 `http://服务器IP:面板端口/<随机路径>/`（启动日志打印完整地址，也可在 `conf/server.json` 的 `panel_prefix` 自定义）。

## 转发规则

规则按所属客户端分组展示：正向规则归入「🚢 服务器」组，穿透/反向规则归入对应「💻 客户端」组。

每条规则显示：状态、实时速率（↑出/↓入，每 2 秒刷新）、累计流量、当前连接数。
TCP 规则每 60 秒自动探测目标可达性，状态列显示「目标通/不通」徽章（穿透规则经隧道探测，顺带验证整条链路；UDP 规则无探测）。
点「图表」看每规则的历史速率折线（30 秒采样，保留 24 小时，仅内存不落盘，重启清零）。

### 新建规则

| 字段 | 说明 |
|---|---|
| 名称 | 仅用于展示 |
| 协议 | TCP / UDP |
| 监听端口 | 正向/穿透在**服务器**上开放；反向在**客户端**本机开放 |
| 方向 | 三选一，见下表 |
| 目标地址 | `host:port`，解析视角见下表；多个用英文逗号分隔即**负载均衡**（轮询分发，单目标故障自动切下一个） |
| PROXY protocol | 向目标写 PROXY 头传递真实访客 IP（v1 文本 / v2 二进制），目标服务需支持解析；仅 TCP |
| 来源白名单 | 每行一个 IP/CIDR；留空不限制。命中失败的连接/包直接丢弃并记日志。对穿透/反向规则，在**监听所在侧**执行 |
| 限速上限 | 规则总带宽上限（Mbps，双向共享），0=不限；超配额的流量排队等待 |
| 连接数上限 | 最大并发连接（UDP 为并发会话数），0=不限；超限的新连接/新访客直接拒绝 |
| 监听端口段 | 新建时填 `5000-5010` 可批量生成多条规则（名称自动加端口后缀） |
| 空闲超时 | TCP 连接超过 N 分钟无数据自动断开（UDP 会话固定 90 秒过期），0=不限 |

| 方向 | 数据链路 | 谁拨目标 | 目标解析视角 |
|---|---|---|---|
| 正向 | 服务器端口 → 目标 | 服务器 | 服务器 |
| 穿透 | 服务器端口 → 客户端内网目标 | 客户端 | 客户端 |
| 反向 | 客户端端口 → 服务器侧目标 | 服务器 | 服务器 |

端口占用规则：正向/穿透在所有服务器侧规则间查重；反向在同一客户端的规则间查重。

### 热生效

- 新增/编辑/删除/启停：立即生效（约 1 秒内下发到相关客户端），无需重启任何进程
- 反向规则的监听结果会回传：启动失败时（如端口被占）失败原因直接显示在规则行
- 客户端离线时规则保留，客户端重新上线后自动恢复

### 编辑弹窗

点击弹窗外空白处或「取消」关闭。

## 客户端

- 每台内网机一条记录，`token` 用于客户端配置，一键复制
- 在线状态、来源地址、上线时间实时刷新
- 删除客户端前需先删除引用它的规则

## 设置

- **异常通知 WebHook**：填通知地址 + 格式（通用 JSON / 钉钉机器人 / 飞书机器人），可「发送测试」。
  触发事件：客户端上线/下线、规则启动失败、客户端反向监听失败、隧道爆破锁定。同事件 60 秒防抖
- **IP 白名单**：每行一个 IP 或 CIDR；在线客户端来源 IP 始终自动放行；免密/有密模式都生效
- **IP 黑名单**：每行一个 IP 或 CIDR，优先于一切放行规则；面板与隧道都拒绝（回环地址豁免，防止把自己锁在外面）
- **配置备份**：导出完整配置 JSON（含密码与 token）；导入恢复规则/客户端/白名单/黑名单/通知/密码，
  本机监听地址与随机路径保持不变
- **修改密码**：`no_auth=false` 时显示，免密模式隐藏

## 监控集成

`GET /<随机路径>/metrics` 输出 Prometheus 文本格式指标（每规则流量/连接数、客户端在线数等），
无需登录但受白名单与随机路径保护，可直接配置给 Prometheus 抓取。

## 日志

最近 300 行运行日志（客户端上下线、规则启停、反向监听失败等），2 秒刷新。

## 服务端运行日志

面板日志只是环形缓冲的最近片段；完整日志看进程输出：
Linux `journalctl -u caochuan -f`；Windows 服务「查看事件查看器」或控制台运行。
